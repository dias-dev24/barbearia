# BRAVO Barbearia

Experiência de barbearia criada para portfólio, com Next.js, React, TypeScript e Tailwind CSS. Marca, equipe e serviços são demonstrativos.

## Etapas

- [x] 1. Identidade visual e página responsiva.
- [ ] 2. API, SQLite e agendamento conversacional sem IA paga.
- [ ] 3. Testes do fluxo, acessibilidade e documentação.

## Executar

Requer Node.js 22.13 ou superior.

```sh
npm ci
npm run dev
```

Abra http://localhost:3000. Nenhum painel administrativo faz parte do escopo.
